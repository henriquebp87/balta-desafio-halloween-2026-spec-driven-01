### Sobre este desafio
Neste desafio o objetivo é consolidar os fundamentos do Spec Driven Development, criando uma constituição, especificação, planejamento e tarefas manualmente para serem implementadas pela IA posteriormente.

#### O que foi implementado
- Uma minimal API com dois endpoints: um para gerar senhas fortes, e outro para recuperar uma senha associada a um GUID fornecido.

Neste processo eu aprendi:
* ✅ Quais os objetivos do SDD
* ✅ No que consiste cada arquivo `.md` utilizado no SDD (`constitution.md`, `spec.md`, `plan.md`, `tasks.md`)
* ✅ Escrever os arquivos `.md` de forma que a IA consiga implementar a especificação
* ✅ Escrever um prompt para que a IA implemente a especificação

## Problema

- Senhas fracas ainda são muito comuns e facilitam ataques de força bruta e adivinhação.

## Solução proposta

- Implementar um gerador de senhas fortes que sigam um padrão pré-definido.
